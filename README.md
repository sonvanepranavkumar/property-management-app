# Property Management Application

A full stack property management web application built with C#, ASP.NET Core, Entity Framework Core and SQL Server.

## Features

- Property management
- Tenant management
- Rent payment tracking
- Expense tracking
- Authentication using ASP.NET Core Identity

## Technology Stack

- C#
- ASP.NET Core
- Entity Framework Core
- SQL Server
- Razor
- xUnit and Moq

## Getting Started

### Prerequisites

- Visual Studio
- .NET 9
- SQL Server

### Installation

1. Clone the repository
2. Open the solution in Visual Studio
3. Configure the SQL Server connection string
4. Apply Entity Framework Core migrations
5. Run the application using Visual Studio

## Testing

Automated tests using xUnit and Moq.
